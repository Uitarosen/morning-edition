PRIVACY — 市販の2024年型SUVから通信モジュールとGPS追跡を完全除去した実践記録

2024 RAV4から
モデムとGPSを
取り除いた

セキュリティ研究者のArkadiyt（Twitter: @arkadiyt）による実践記録が452ポイント・258コメントを集めて本日のトップに。2024年型トヨタRAV4ハイブリッドに搭載された通信モジュールとGPS追跡機能を完全に除去するプロセスを詳細に文書化した技術記事です。現代の「コネクテッドカー」は常時インターネット接続を持ち、位置情報・走行パターン・運転挙動をメーカーのサーバーに送信し続けています。著者はリバースエンジニアリングでTCU（Telematics Control Unit）の配線を特定し、モデムと位置情報モジュールを物理的に除去。車の基本機能（走行・ナビ・安全系）は維持しながら、プライバシーを回復させた経緯を詳述しています。HNでは「これこそが真のオーナーシップ」「トヨタのデータ収集規約の細かさが問題」「保証問題のリスクを取っても実行した姿勢に敬意」という熱いコメントが続いています。
何を除去したか
TCUとGPSモジュール
Telematics Control Unit（通信制御ユニット）と独立したGPSアンテナ／モジュール。物理的に取り外すことで電源供給とデータ送信を完全遮断
影響した機能
Connected ServicesのみOFF
Toyota Connected Servicesアプリ・緊急通報（eCall）・リモートエンジンスタートが無効化。走行・ナビ・ADAS・Bluetooth・CarPlayは正常動作
技術的アプローチ
物理的切断
配線図をリバースエンジニアリングで特定し、ダッシュボード内部のTCUユニットへのアクセス経路を確保。ソフトウェア無効化ではなく完全物理除去を選択
HNの反応
452pt / 258コメント
「完全な再現手順を公開してくれて感謝」「欧州ではeCallは法定義務なので合法性が問われる」「他の車種への応用ガイドを求める声多数」

DEV TOOLS — JavaScriptランタイムのBunがZigからRustへの書き直しをメインブランチにマージ

BunをRustで
書き直すPRが
マージされた

JavaScriptランタイムBunの公式GitHubリポジトリで「Rewrite Bun in Rust」というPRがマージされたというニュースが419ポイント・501コメントを集めています。BunはもともとZig言語で書かれた高速なNode.js互換ランタイムとして知られていましたが、このPR（#30412）でコアコンポーネントのRustへの移行が正式にマージされました。ZigからRustへの変更はパフォーマンス・エコシステム・長期的なメンテナビリティを考慮した判断とされており、HNでは「Zigコミュニティにとって痛手」「Rustのエコシステムの成熟が決め手だったのでは」「Bunがここまで大きくなったからこそ安定した言語基盤が必要」「パフォーマンス測定値が出るのを待ちたい」という議論が501コメントに及んでいます。JavaScriptツールチェーンの書き直しブームが続く中、BunのRust移行は2026年最大のdev tools動向の一つです。
なぜZigからRustへ
Zigは低レベル制御に優れるがエコシステムが小さい。RustはCratesによる豊富なライブラリと、メモリ安全性の保証、大きなコントリビューターコミュニティを持つ
何がRustになるか
PR #30412ではコアランタイムの一部が対象。JavaScriptエンジン（JavaScriptCore）はそのまま。段階的な移行で既存の互換性を維持しながら書き直す計画
Zigコミュニティへの影響
Bunはプロダクションで実証されたZigの最大プロジェクトの一つだった。今回の移行でZigの「実用事例」が減少するとして、コミュニティから失望の声も出ている
今後の展開
Bun v2.x以降でRust移行の効果が測定可能になる見込み。Node.js互換性・バンドル速度・メモリ使用量がベンチマークの焦点になると予想される

①
今すぐ確認すること

リポジトリの内容

SECURITY — Apple M5チップを搭載したmacOSで初めて公開されたカーネルメモリ破壊エクスプロイト

Apple M5で
初の公開カーネル
メモリ破壊エクスプロイト

セキュリティ研究者がApple M5チップ搭載macOS上で動作するカーネルメモリ破壊の概念実証を公開し、149ポイント・23コメントを集めています。blog.calif.ioに掲載された技術詳細では、M5の新しいアーキテクチャ上でのmacOSカーネルに存在する脆弱性を利用し、ユーザーモードから特権昇格を引き起こす手法を実証。M系チップのPAC（Pointer Authentication Codes）やMTE（Memory Tagging Extension）などのセキュリティ機能を回避する技法も含まれています。「First public」という表現は、M5環境での最初の公開PoCであることを意味しており、研究者はAppleに事前に報告済みとしています。HNでは「Appleのセキュリティ速報を今すぐ確認すべき」「Responsible Disclosureとして事前通知済みであれば公開は適切」「M5のPACがすでに回避されているという事実が重要」という反応が出ています。
脆弱性の性質
カーネルメモリ破壊（kernel memory corruption）により権限昇格が可能になる脆弱性。ローカルでの悪用が前提となるが、他の脆弱性と組み合わせてリモート攻撃チェーンに使われるリスクがある
M5固有の課題
Apple M5はPAC・PPL・APRR・MASLRなど多層的な防御機構を持つ。本PoC は特定の条件下でこれらを回避することを実証しており、Appleのハードウェアセキュリティの限界を示す
Appleへの開示
研究者はAppleに事前通知済みと主張。CVEの割り当て・パッチリリースのタイムラインは記事投稿時点では未公表。macOS Sequoia / Venturaの最新版が推奨
対処法
macOSを最新バージョンに更新する。SIP（System Integrity Protection）が有効であることを確認。Apple Security Updatesページを定期的に確認するのがベストプラクティス

AI POLICY — 存在しない参考文献をAIで生成した論文に対してarXivが1年間の投稿禁止措置を導入

arXiv新ポリシー：
ハルシネーション参考
文献で1年間禁止

機械学習研究者のThomas Dietterichがツイートした情報によると、arXivがAIによって生成された「ハルシネーション参考文献」（存在しない論文の引用）を含む投稿に対して1年間の投稿禁止措置を適用する新ポリシーを導入したと報じられています。102ポイント・9コメントながらHNフロントページに浮上しており、研究コミュニティへの重大なシグナルとして注目されています。LLMを使った論文執筆支援が増える中で、引用検証をしないままAIが生成した参考文献リストをそのまま使う「コピペ投稿」が急増している問題への対応です。HNでは「arXivはプレプリントサーバーとしてはこれが正しいスタンス」「ピアレビューのある学術誌も同様のポリシーを取るべき」「1年は適切か？永久禁止でもいいのでは」という議論が展開されています。
なぜ問題か
ハルシネーション参考文献は科学的誠実性の根幹を損なう。引用されたと思われる論文の著者や引用ネットワーク全体に誤った情報が伝播し、後続研究が歪む可能性がある
arXivの検出手法
CrossRef・Google Scholar・Semantic Scholarとの照合による参考文献の実在確認。完全自動化はされておらず、人間のモデレーターによる確認も組み合わせていると見られる
研究者への実務的影響
AI支援で論文を書く場合は必ず参考文献を手動で全件確認すること。Google Scholar・Semantic Scholar・CrossRefで実在と正確なメタデータを照合する作業が必須になる
業界への波及
NeurIPS・ICML・Nature系など主要学術誌も同様のポリシー強化が予測される。LLMによる論文執筆支援ツールには参考文献検証機能の組み込みが求められるようになる

CREATIVE TECH — 1981年製CGA（カラーグラフィックスアダプタ）で60fps動画を再生する「GlyphBlaster」

CGAで60fps動画を
実現——
GlyphBlaster

MartyPCというPC-8088/8086エミュレーター開発者によるブログ記事「60fps Video on a CGA? – The GlyphBlaster」が66ポイント・9コメントを集めています。CGA（Color Graphics Adapter）は1981年にIBMが発表した最初期のカラーグラフィックスカード。最大解像度は320×200・4色という極めて貧弱なハードウェアを使って60fpsの動画再生を実現するという、あり得ないハードウェアハックです。GlyphBlasterはCGAのテキストモードを逆用して、フォントROM内の文字グリフを動的に書き換えることで実質的なピクセル操作を行うというトリックを使用。「なぜCGAでそんなことができるのか」というアーキテクチャの深い理解から生まれた創造的エンジニアリングで、デモシーン文化と低レベルプログラミングの粋が詰まった作品です。「これを見て久しぶりにレトロPCを引っ張り出したくなった」「なぜこれができるのか仕組みを解説した部分が最高」という反応が寄せられています。
CGAとは
Color Graphics Adapter。IBM PC初期（1981年）のグラフィックスカードで、320×200・4色または640×200・2色が限界。現在のGPUとは比べ物にならないスペックだが、テキストモードを持つ
GlyphBlasterのトリック
CGAのテキストモードでは文字コードごとにフォントグリフが参照される。このグリフをリアルタイムで書き換えることで、テキストモードを実質的なピクセルフレームバッファとして使い60fps描画を実現
技術的な達成
CPUタイミング・メモリバス幅・CRTコントローラの水平帰線期間を精密に利用して、1フレーム16.6ms以内にフォントRAM全体を書き換えるという離れ業。エミュレーターで実証
デモシーン文化との接続
1980〜90年代のデモシーンプログラマーが実践した「制約の中の創造性」の現代的継承。ハードウェアの限界を正確に理解することで限界を超える、という本質的なハッキング精神

WEIRD SCIENCE — 化石の分析が覆した通説：ムカデ・ヤスデの祖先は陸上ではなく水中で多足化した

化石が示す——
ムカデの祖先は
水中で脚を進化させた

Phys.orgに掲載された古生物学研究が65ポイント・2コメントを集めています。現在の常識では多足動物（ムカデ・ヤスデの祖先）は陸上生活に適応する過程で多数の脚を進化させたと考えられていましたが、新たに発掘・分析された古代海洋生物の化石がこの通説を覆しました。研究によると、多足動物の最も古い祖先は海洋環境に生息しており、多数の脚は陸上移動のためではなく海底の堆積物の中を動き回るための適応として先に進化していたと示されています。陸への上陸（海から陸への転換）は脚の進化より後の出来事だったという新しいシナリオが提唱されています。「脚は上陸のためではなく海の底で先に生えていた」というこの逆転の発見は、動物の多様化プロセス全体の理解を変える可能性があります。
何が発見されたか
多足動物（ムカデ・ヤスデ類）の最古の祖先に当たる化石が海洋堆積物から発見。多数の脚が海底生活への適応として先に進化していたことが、形態的特徴の分析で示された
覆された通説
従来：多足動物は陸上生活で歩行効率を高めるために脚を増やした。新説：脚は海底の堆積物や岩礁の間を動き回るための適応として水中で先に進化し、その後陸に上がった
進化生物学的意義
「陸上動物の形態は陸上環境への適応で生まれた」という前提が崩れる事例。多くの陸上動物の形質が実は水中環境で既に進化していたという「前適応」の概念を強化する
なぜ面白いか
現代のムカデやヤスデを見るとき、それらの脚は「陸を歩くため」ではなく「海底をかき分けるため」に作られたオリジナルの設計が転用されたものだという視点が加わる
