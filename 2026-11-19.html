セキュリティ / Nginx / RCE脆弱性 / HTTP/2 — 2026-11-19

認証なしでリモートコード実行
NginxのHTTP/2処理に致命的な脆弱性

Wiz Researchが発見したNginxの深刻な脆弱性が956ポイント・437コメントを獲得し、今日のHNで最大の注目を集めた。HTTP/2プロトコル処理の欠陥を悪用することで、認証なしに対象サーバ上で任意のコードを実行できる（Unauthenticated RCE）。NginxはWebの約34%でリバースプロキシ・Webサーバとして稼働しており、影響範囲は極めて広い。パッチ適用が今すぐ必要な最優先対応案件。
脆弱性の仕組み
HTTP/2フレーム処理のメモリ安全性の欠陥
細工されたHTTP/2リクエストをNginxに送るだけで認証なしにRCEが成立する。Wiz Researchが実証コード（PoC）を確認しており、既に悪用が開始される可能性がある。CVE番号はレポート内に記載。
影響範囲
世界のWebの約34%がNginxを使用
リバースプロキシ・ロードバランサーとして使われるNginxの前段に当たるため、背後のアプリサーバへの踏み台になるリスクも高い。Nginxをk8sのIngress Controllerとして使っている環境も対象。
今すぐやること
Nginxを最新版にアップデート
① `nginx -v` でバージョン確認。② パッケージマネージャまたは公式サイトから最新安定版へアップデート。③ HTTP/2を使っていない環境でも念のため対応を推奨。④ WAFでHTTP/2異常リクエストの検知ルール追加を検討。

プライバシー / DNS / 検閲 / Quad9 — 2026-11-19

「海賊版対策にDNSを使うな」
Quad9がフランス市場を離脱した理由

プライバシー重視のDNSリゾルバー「Quad9」がフランスでのサービス提供を停止したことを伝える記事が530ポイント・194コメントを集めた。フランスの裁判所がQuad9に対し、特定のドメインをDNSレベルでブロックするよう命じた判決を受けての措置。Quad9は「DNSリゾルバーはコンテンツ制御の適切な場所ではない」として対応を拒否し、フランスから撤退することを選んだ。インターネットの分断とDNS検閲の行方に議論が集中している。
何が起きたか
フランスの知的財産権保護団体がQuad9に対し、海賊版コンテンツへのアクセスに使われるドメインをDNSレベルでブロックするよう求める訴訟を起こし、裁判所が命令を発した。Quad9はスイスのNPOが運営するプライバシー重視のリゾルバーで、ユーザーのDNSクエリを記録・販売しない設計を貫いている。命令への対応（コンプライアンス）はその原則に反するとして撤退を選択。
なぜこれが重要か
「DNSリゾルバーがコンテンツ検閲の手段になる」という先例が生まれることへの懸念が焦点。DNSブロッキングは簡単に迂回できる（VPNや代替リゾルバーへの切り替え）ため実効性は低い一方、プロバイダーや中立サービスへの義務が広がる危険がある。EFF・電子フロンティアなどのデジタル権利団体が注目しているテーマ。

AI研究 / 推論効率 / LLM / アーキテクチャ — 2026-11-19

「推論を385倍効率化」——
エネルギーベース推論器が示すLLMの次の形

「Energy-Based Reasoners」と題した研究プロジェクトページが293ポイント・49コメントを獲得した。現行のLLMが推論時に行うトークン生成のコストを385倍削減できる新しいアーキテクチャを提案。エネルギーベースモデル（EBM）の原理をLLM推論に適用することで、「考える量」を入力の複雑さに応じて動的に調整する仕組みを実現している。AIの「賢さ」を維持しながら推論コストを劇的に下げるアプローチとして注目を集めている。
仕組みのポイント
従来のLLMは全てのトークンに同等の計算コストをかけるが、エネルギーベース推論器は「難しい問題には多く、簡単な問題には少なく」計算を割り当てる。エネルギー関数が問題の難易度を評価し、最適な計算量を動的に決定する。これにより平均的なワークロードで推論コストが385倍改善されるという結果が得られた。
実用上の意味
AIエージェントやリアルタイムアプリケーションで推論コストは最大のボトルネックの一つ。385倍の効率化が実用化されれば、現在は不可能な「毎秒何百もの推論ステップを連続実行するエージェント」が現実的なコストで動かせる可能性がある。研究段階だが業界的に注目度が高い。
