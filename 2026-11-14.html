クラウドを切り離せ
——Coway空気清浄機を解体した話

エンジニアのscottjgが、自宅のCoway空気清浄機のクラウド依存を断つためにデバイスを分解・通信解析し、ローカルのみで動作させる方法を詳細なブログ記事として公開した。631ポイント・186コメントと大反響。IoTデバイスのプライバシー侵害とクラウド強制への静かな反撃として、HNで強く支持された。フィルター交換アラームから使用統計まで、あらゆるデータがメーカーサーバーに送られていたことが明かされている。
何が送信されていたか
フィルター寿命・稼働時間・空気質データ
パケットキャプチャにより、デバイスは定期的にCowayのサーバーへフィルター交換時期、使用時間、PM2.5センサー値を送信していることが判明。メーカーの利用規約には「匿名データ収集」と書かれているが、デバイスIDが付与されており実質的に個人特定が可能。
ローカル制御への道
UART経由でコマンド直接送信
デバイス内部のメインボードにUARTピンを発見。115200ボーで接続したところ、非暗号化のコマンドプロトコルが確認できた。ファン速度・フィルターリセット・電源ON/OFFをローカルから完全制御可能。Home AssistantやESPHomeとの統合例も記事内で紹介されている。
HNコメントの反応
「これが当然あるべき姿」の声多数
186コメントの多くが同様の経験を共有。「Ecobeeサーモスタットも同じ」「SwitchBotもローカルAPIがある」と代替事例が続出。批判的意見は少なく「家電製品は外部サーバー依存なしで動くべき」という共通認識が浮かび上がった。作者はGitHubにコード一式も公開済み。

変わった科学 / 歴史 / 1960年の予言 / 数学 — 2026-11-14

昨日は「運命の日」だった
——1960年の予言が今日に届く

1960年にScience誌に掲載された論文「Doomsday: Friday, 13 November, A.D. 2026」がHNで416ポイント・293コメントを集めた。著者Heinz von Foersterらが人口増加の数学的外挿から「文明が無限大の密度に達する特異点」として計算した日付が、まさに昨日2026年11月13日（金曜日）だった。66年前の数式が今日に正確に刺さるという事実が、奇妙なタイムカプセル感覚でHNを沸かせた。
何を予測したのか
1960年当時の世界人口増加曲線を外挿すると、2026年11月13日に人口が数学的に「無限大」になる——という半ばジョークを含む計算結果。著者のvon Foersterは著名なサイバネティクス研究者で、論文は本気の予測ではなく「指数成長の限界を考えよ」という警鐘として書かれた。
実際どうだったか
当然、人類は終わらなかった。しかし世界人口は2026年時点で約85億人に達しており、1960年の約30億人から3倍近くに増加。FAA全米グラウンドストップが重なったことで「何かが起きている日」としてますますミーム化した。HNコメント: 「昨日FAAが全停止したことと無関係ではないと思いたい」。
なぜ今も語られるか
論文そのものよりも「科学者が66年後の特定の曜日と日付まで書き残した」という事実が面白い。タイムカプセル的な性格と、数学的厳密さと半ばジョークの同居が時代を超えて引用される理由。現代のAI成長曲線にも同じ議論が適用できるとして、AIコミュニティで再評価されている。

AI / 数学 / ゲーデル / 歴史的発見 — 2026-11-14

AIがゲーデルの手書きノートを解読
——数百の未発表定理を発見

不完全性定理で知られる数学者クルト・ゲーデルの膨大な手書きノートをAIが解析し、数百もの証明済み定理が眠っていることをThe Guardianが報じた。270ポイント・80コメント。速記に近い独自表記で書かれたゲーデルのノートは長年専門家を悩ませてきたが、OCR+LLMの組み合わせが突破口を開いた。今後の数学・論理学への影響が注目される。
なぜ未解読だったのか
ゲーデルは独自の略記法・記号体系を使っており、ドイツ語・英語・記号が混在。プリンストン高等研究所に保管された数千ページのノートは整理されておらず、解読に必要な文脈知識（彼の思考の流れ）がないと意味が通じない。従来の研究者による手作業では1ページの解読に数日かかることもあった。
AIがどう解いたか
高精度OCRでスキャン後、ゲーデルの既刊論文を学習したLLMが略記法のパターンを学習。文脈から記号の意味を推測しつつ形式論理の検証ツールで証明の妥当性を確認するパイプラインを構築。研究チームは「AIが数学的直感を持ったわけではなく、パターン認識と形式検証の組み合わせが機能した」と説明。
HNコメントの反応
「これは数学史の転換点になるかもしれない」という期待と「査読を経ていない段階で"数百の定理"と報じるのは誇張では」という懐疑が混在。数学者のコメント: 「内容の質が重要——今まで誰も思いつかなかった結果なのか、既知の系だが未発表だったのかで意味が全く違う」。

教育 / UX / Apple / テクノロジー批判 — 2026-11-14

iPadでPowerPointを開くのに
16クリック必要——教師が嘆く

「iPadで生徒がPowerPointファイルを開くまでに16回タップしなければならない」という教師のReddit投稿が197ポイント・104コメントを集めた。iCloud Drive→OneDrive→Keynote変換→開く、という迷宮のような操作フローが問題の本質。エンタープライズ向けに複雑化したAppleのエコシステムと、Microsoft/Apple間の互換性問題が教育現場の日常的な摩擦を生み出している実態が浮き彫りになった。
16クリックの内訳（例）
ホーム画面→Filesアプリ→OneDriveフォルダ→クラスフォルダ→ファイル長押し→共有→Keynoteで開く→変換確認→Keynote起動→読み込み待機→プレゼンモード…という手順。学校のMDM設定とセキュリティポリシーがさらにステップを増やしているケースも。設定一つで改善できるはずが、IT管理者の権限制約で変更不可という構造的問題も。
HNコメントの洞察
「これはAppleではなくMicrosoftのOffice 365とMDMの問題」「Googleスライドを使えばいい話では」と代替案も多数。しかし「学校区のIT調達はMicrosoftとAppleのセットで決まることが多く教師に選択肢がない」という現実も指摘された。教育機関のテクノロジー調達が現場ユーザーの声を反映していない問題の縮図として多くの共感を得た。
解決策として挙げられた方法
ショートカットアプリでワンタップ起動フローを作る方法、OneDriveをデフォルトアプリとして設定する方法、そもそもPDFで配布するという実用的な提案が多かった。「テクノロジーが教育の障壁になっている」という根本的な問題提起として多くの教師・保護者・IT管理者が共感した投稿。

AI研究 / JEPA / 世界モデル / 機械学習 — 2026-11-14

600回の実験で分かったこと
——JEPA世界モデルの実態

研究者のHaddy Alchaerが600回以上の実験を通じてJEPA（Joint Embedding Predictive Architecture）世界モデルの挙動を体系的に調査した結果を公開した。180ポイント・31コメント。YannLeCunが提唱したJEPAはLLMとは異なるアプローチの世界モデルとして注目されているが、実際に「何ができて何ができないか」を大規模に検証した研究は少なかった。再現性と実用性の観点から非常に価値ある一次資料。
JEPAとは何か
Joint Embedding Predictive Architecture——入力を直接予測するのではなく、潜在空間（埋め込み空間）上での予測を学習するアーキテクチャ。ピクセル単位の再構成が不要なため、意味的な特徴を効率的に学習できるとされる。YannLeCunはこれがLLMよりも「世界の仕組みを理解する」AIに近いと主張しており、業界で注目度が高い。
600回の実験で判明したこと
世界モデルとしての能力は特定のドメインで顕著——特に時間的一貫性が必要なタスクではLLMベースより優れたパフォーマンスを示した。一方で常識推論や複数ステップの因果推論では期待ほどの性能向上がなかったことも正直に報告。「超えられた壁」と「まだ越えられていない壁」の両方が丁寧に整理されており、次の研究の出発点として評価が高い。
実践的な示唆
著者は「JEPAとLLMは競合ではなく補完的」という結論を提示。ロボット制御・リアルタイム環境理解にはJEPA、言語・抽象推論にはLLMという棲み分けが現時点では最適とみている。コードと実験ログはGitHubで公開されており、追試が容易。HNコメント: 「こういう泥臭い実験レポートこそが最も価値ある研究」。

AI / コンテンツ品質 / マニフェスト / 業界論考 — 2026-11-14

AIスロップへの宣戦布告
——「No AI Slop」マニフェスト公開

「No AI Slop」と題したマニフェストが公開され、AIが大量生成する低品質コンテンツ（スロップ）への反発運動として131ポイント・75コメントを集めた。ブログ記事・SEO用ライティング・ソーシャルメディア投稿に氾濫するAI生成コンテンツの質の低さへの怒りが凝縮されている。「スロップ」という造語自体がすでに業界内でミーム化しており、このマニフェストはその反旗を明確に言語化したものとして注目された。
「スロップ」とは何か
AI生成の、読者にとって無価値な大量コンテンツ。典型的な特徴: ①一般的すぎて実際には何も言っていない ②ハルシネーションを含む可能性が高い ③SEO目的でキーワードを詰め込んでいる ④人間の知識・経験・視点が皆無。検索エンジンや情報の海を汚染しているとマニフェストは主張する。
マニフェストの主張
AIツール自体は否定しない——問題は「AIを使って考えること」ではなく「AIに考えさせて自分は何も思考しないこと」。著者はAIを道具として使いつつも、最終的な判断・個性・経験は人間が担うべきだと主張。バッジ「No AI Slop」をコンテンツに貼ることで人間による高品質なコンテンツを識別できるようにする提案も含む。
HNでの議論
「スロップかどうかは出力の質で判断すべきで、AIかどうかは関係ない」という反論も多い。「人間が書いた低品質コンテンツもスロップでは」という意見も。しかし「AIは量産を劇的に下げる——問題はスケールにある」という視点が支持を得た。コンテンツの質とオリジナリティへの関心が業界全体で高まっている証左。

AI / OpenAI / ロボティクス / 業界動向 — 2026-11-14

OpenAI、ロボティクスチームを解散
——汎用モデルがロボットを動かす時代へ

OpenAIが専任のロボティクス研究チームを解散させたとFortuneが報じた。121ポイント・54コメント。理由は汎用AIモデル（GPTシリーズ）が直接ロボット制御システムに組み込めるほど高度化したため、専門部門の必要性がなくなったから。2019年に解散した前のロボティクスチーム以来2度目。「専門チームより汎用モデル」という戦略転換が業界全体に波及するかが注目点。
なぜ今解散なのか
GPT-5以降のモデルが視覚・物理シミュレーション・マルチステップ計画の能力を格段に高め、ロボットの「脳」として直接使えるようになったため。従来はロボット専用の強化学習・模倣学習パイプラインが必要だったが、プロンプトエンジニアリングとツール呼び出しで代替できるケースが増えた。Figure AI・1X・Physical Intelligenceなどのパートナー企業がその実証実験を担う形に移行。
業界への影響
「汎用モデルがドメイン特化モデルを食う」というパターンがロボティクスにも波及したことを象徴する出来事。同様の圧力がバイオ・法律・医療特化チームにもかかっている可能性がある。一方でロボット専門家は「物理世界との相互作用の安全性・信頼性確保は汎用モデルだけでは難しい」と反論。HNコメント: 「Figureは喜んでいるはず——競合がいなくなった」。

クリエイティブソフト / FM音源 / オープンソース / WebAudio — 2026-11-14

FM-1 Workbench
——ブラウザで動くオープンソースFM音源

M-VAVE社がFM-1シンセサイザーのブラウザベース・オープンソースワークベンチ「FM-1 Workbench」を公開した。121ポイント・78コメント。WebAudioを活用したFM（周波数変調）音源のリアルタイム編集環境で、インストール不要でFMシンセの醍醐味を体感できる。ハードウェアシンセの操作感をブラウザで再現した設計と、MIDIキーボード対応が評価されている。
FM音源とは何か
周波数変調（Frequency Modulation）合成——1基準波を別の波で変調することで倍音の豊かなサウンドを生成する技術。ヤマハDX7（1983年）で広く普及し、80〜90年代のエレクトリックピアノ・ベースサウンドの定番に。デジタルながら複雑で有機的なサウンドが出せるが、パラメータが直感的でないため「難しい音源」として有名。
FM-1 Workbenchの特徴
ブラウザ内でオペレーター（音源ブロック）の接続図をビジュアルで操作できるUIを採用。エンベロープ・LFO・フィードバック量をリアルタイムに変更しながら音の変化を確認できる。MIDIキーボードを繋げばリアルタイム演奏も可能。コードはGitHubでMITライセンス公開。HNコメント: 「FM音源を初めて直感的に理解できた」という声多数。

AI / セキュリティ / 研究 / モデル汚染 — 2026-11-14

AIモデルが「重み空間ウイルス」を
伝播させられる可能性——新研究

研究者らがAIモデルのパラメータ（重み）空間でウイルス的な汚染が伝播できることを示す論文をalphaXivで公開した。120ポイント・43コメント。モデルのファインチューニングや蒸留プロセスを通じて悪意あるパターンが次世代モデルに引き継がれる「weight-space misfolding」という概念を提唱。タンパク質の折りたたみミスによる神経変性疾患（プリオン病）からのアナロジーが斬新と評された。
「重み空間ウイルス」とは
悪意あるパターンをモデルの重みに埋め込み、そのモデルからファインチューニング・蒸留・MoEマージを通じて派生したモデルにも汚染が引き継がれる攻撃。表面的な動作テストでは検出困難で、特定の入力条件下でのみ悪意ある挙動が発現する。プリオン病との類比：プリオンタンパク質が正常タンパク質を異常折りたたみに誘導するように、汚染された重みが正常なモデルを「感染」させる。
実際の脅威か、理論か
論文はまだ査読前のプレプリント（alphaXiv掲載）。実証実験は限定的な設定下でのみ成功しており、実用的な大規模モデルへの適用可能性は不明。HNコメント: 「サプライチェーン攻撃のAI版として概念的に重要」という意見と「誇大な表現では」という懐疑論が混在。しかしモデルのサプライチェーンセキュリティへの関心を高める効果は認められている。

生物学 / 老化 / タンパク質 / 変わった科学 — 2026-11-14

炎症を起こさずに
老化を進めるタンパク質——新発見

Nature誌が、炎症反応を引き起こさずに老化を進行させる新たなタンパク質の発見を報じた。58ポイント・11コメント。従来の老化研究では「慢性炎症が老化を加速する」という「inflammaging（炎症老化）」仮説が主流だったが、このタンパク質は炎症シグナルを迂回する全く別の経路で細胞の老化を促進する。老化の分子メカニズム解明に新たな視点をもたらす発見として注目される。
発見の意義
「老化 = 炎症」という単純な図式への疑問符。このタンパク質は炎症マーカーが陰性でも老化関連の細胞障害を引き起こすことが確認された。これはアンチエイジング薬や老化治療において「炎症を抑えればよい」という方針だけでは不十分な可能性を示唆する。タンパク質の具体的な名称と作用機序は論文内で詳述されており、ドラッグターゲットとしての可能性も示唆されている。
HNコメントの反応
生物系の研究者からは「inflammagingへの反例として重要な論文」という評価が多い。一方で「マウス実験の結果がヒトに適用できるかは慎重に判断すべき」という標準的な懐疑コメントも。老化研究への一般的な関心の高さもあり、コメント数は少ないものながら内容の濃い議論が展開された。Longevity分野での応用研究が今後加速する可能性が指摘されている。
